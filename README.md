# Tanit Hub website

Live: https://conanarchi.github.io/tanit-hub/  (GitHub repository Conanarchi/tanit-hub, GitHub Pages from the main branch root)

To update the live site: edit the files here, then on GitHub open the repository, click Add file, then Upload files, and drop the changed files (files inside assets go in the assets folder).

No build step. Open index.html to preview.
